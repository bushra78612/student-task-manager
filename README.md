# Student Task Management System

## Project Purpose

The Student Task Management System is a simple browser-based application designed to help students organize and manage their academic tasks.

## Current Features

- Display student tasks
- Add a new task
- Enter task title and description
- Validate empty task submissions
- Responsive web page layout

## Project Structure

- index.html - Main web page
- style.css - Website styling
- script.js - Task functionality
- README.md - Project documentation
- .gitignore - Files excluded from Git tracking

## How to Use

1. Open index.html in a modern web browser.
2. Enter a task title.
3. Enter a task description.
4. Click the Add Task button.
5. The new task will appear in the task list.
